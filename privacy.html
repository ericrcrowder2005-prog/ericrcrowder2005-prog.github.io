Privacy policy

Last updated: November 25, 2026

This policy covers the [CHANNEL NAME] Uploader (the "app"), a personal tool run by [YOUR NAME], the owner of the [CHANNEL NAME] YouTube channel. The app publishes the channel's own videos to YouTube using YouTube API Services. It has one user: the channel owner.

Google and YouTube data the app accesses

The app signs in only to the channel owner's Google account, with these permissions:

  • Upload videos (youtube.upload): to upload the channel's finished videos.
  • Manage the channel's videos (youtube.force-ssl): to set each video's thumbnail and closed captions, update its title, description and publish time, and read the titles of the channel's recent uploads so the same video is never posted twice.

The app does not access any other person's account or data. It does not read comments, subscribers, viewer data, email, contacts or files.

How the data is used

Data is used only to upload and manage the channel owner's own videos on the owner's own channel. It is not used for advertising, profiling or any other purpose.

What the app stores

  • A sign-in token (an OAuth refresh token), kept in an encrypted secret store (GitHub Actions secrets) or in a file on the owner's computer that only the owner can read.
  • An upload log of the channel's own uploads: video ID, title and upload time. It is kept in the owner's private code repository.

Nothing is stored about anyone other than the channel owner.

Sharing

No data is sold, rented or shared with anyone. Video files and their details are sent only to YouTube, as part of uploading them.

Keeping and deleting data

The sign-in token is kept until the owner revokes it or deletes it from the secret store. The upload log is kept for as long as the channel uses the app, and the owner can delete it at any time. Access can be revoked at any time at myaccount.google.com/permissions, which stops the app from reaching the account.

Google API Services User Data Policy

The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

The app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Changes

If this policy changes, the new version will be posted on this page with a new date.
